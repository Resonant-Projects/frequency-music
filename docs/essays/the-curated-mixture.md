# The Curated Mixture

_Freq - June 5, 2026_

---

## Before Separation Comes Selection

The recent extraction set makes source separation look less like a single heroic algorithm and more like a chain of editorial decisions.

FSD50K-Solo begins by asking which recordings are allowed to count as single-source examples. SR-CorrNet asks which spatio-spectro-temporal correlations should be treated as evidence for a recoverable speaker. The streaming SpeechLLM asks when enough audio has accumulated to justify a commitment. Each system is doing more than classification. It is deciding what kind of ambiguity can remain in the material before action becomes unreliable.

That is also an orchestration problem.

An orchestration is not only a set of instruments sounding together. It is a controlled training environment for the listener. It teaches which cues matter, which overlaps are tolerable, and which coincidences should bind into a source. A flute doubled by muted violin is not just a color. It is a curated mixture whose internal evidence has been arranged so the ear either fuses it into one cause or keeps it as two related causes.

## Clean Does Not Mean Simple

The single-source dataset work is especially useful because it refuses to treat cleanness as obvious. A nominally isolated event may still carry background interference, room identity, accidental overlap, or ambiguous onset structure. So the system manufactures clean witnesses and controlled mixtures, then uses them to judge real recordings.

Composition can borrow that logic. Instead of treating a solo statement as the natural origin of a piece, treat it as a calibration event. The opening gesture teaches the ear what a later mixture is allowed to preserve, corrupt, or counterfeit.

A practical sketch:

- Establish a compact source with clear spectral envelope, onset behavior, and register.
- Reintroduce it inside a denser texture while preserving only one or two cues.
- Add a second layer that shares one cue but contradicts another.
- Let the listener's binding decision become the musical tension.

The result is not merely "theme and variation." It is dataset design in time: the piece controls its own examples, counterexamples, and ambiguous cases.

## The Compositional Payoff

The old question is: can the listener hear the line?

The sharper question is: what evidence has the piece supplied for the line to remain a line?

That moves orchestration toward experimental design. A composer can vary evidence quality the way they vary harmony or dynamics. Strong correlation produces objecthood. Weak correlation produces texture. Conflicting correlation produces shimmer, misdirection, or split identity. Delayed correlation produces recognition after the body has already responded.

This is a rich zone for tools. A useful composition interface would not only display pitch, loudness, and spectrum. It would estimate cue agreement across layers: common onset, spectral overlap, modulation coherence, spatial stability, register continuity, and timbral similarity. The composer could then shape sourcehood directly, making a mixture more or less provable by ear.

The shared lesson from these extractions is simple:

**A mixture is not raw material waiting to be separated. It is a curated argument about what counts as a source.**
