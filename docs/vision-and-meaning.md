# Vision and Meaning

## Purpose

Frequency Music exists to turn research, felt experience, composition, and public reflection into a single accumulating practice. It is not only a workflow for collecting sources or generating experiments. It is a long-horizon system for discovering which structures in music matter, which claims survive contact with making, and which ideas become meaningful enough to publish, revisit, and refine.

## North Star

Build a research-to-composition practice that can:

- generate testable musical ideas from serious inquiry
- evaluate those ideas through embodied listening and artistic output
- preserve both successful and failed experiments as durable knowledge
- gradually articulate a distinctive public point of view about music, structure, resonance, and meaning

## What This Project Is

Frequency Music is:

- a lab for turning sources, notes, and hypotheses into compositional experiments
- a memory system for tracking what changes perception, musicality, and bodily response
- a discipline for comparing intuition against evidence, craft, and repeated listening
- a publishing engine for selected findings, not just a private notebook

## What This Project Is Not

Frequency Music is not:

- a generic knowledge-management system
- a content mill for essays or AI-generated summaries
- a medical or wellness claims platform
- a place where speculative ideas are treated as established truth
- a music-production tracker divorced from inquiry

## Meaning Framework

Meaning in this project is accumulated significance across four linked domains:

1. Inquiry: a question is worth pursuing because it clarifies a structure, tension, or possibility in music.
2. Felt response: an experiment matters when it produces a repeatable bodily, perceptual, or emotional effect.
3. Artistic output: an idea matters more when it survives contact with composition and becomes real music instead of remaining only a concept.
4. Public articulation: the work becomes culturally legible when it can be explained, published, and revisited without overstating certainty.

Meaning is therefore not one thing. It is the overlap between understanding, sensation, craft, and expression.

## Rigor, Embodiment, Composition, and Editorial Publishing

### Rigor

Rigor keeps the project from confusing activity with learning. It requires traceability, comparable experiments, clear claims, explicit revisions, and a distinction between what is evidence-backed and what is merely suggestive.

### Embodiment

Embodiment keeps the project from collapsing into abstraction. Music is not only a set of ratios, concepts, and citations. It is also a bodily event. The system should preserve context, felt response, and the language needed to describe subtle changes in perception.

### Composition

Composition is the proving ground. A hypothesis that cannot become a recipe, a sketch, or a track may still be interesting, but it has not yet earned the same weight as a musically generative idea.

### Editorial Publishing

Publishing turns private inquiry into a public practice. It is not the place to exaggerate conclusions. It is the place to present what was tried, what changed, what remains unresolved, and why it matters.

## Core Tensions to Preserve

The project should preserve, not flatten, the following tensions:

- imagination and epistemic discipline
- wonder and skepticism
- bodily response and analytical structure
- lab-like comparability and real musicality
- private exploration and public accountability
- fast experimentation and slow accumulation of doctrine

These tensions are productive. If one side overwhelms the other, the project becomes either sterile or credulous.

## Evidence, Inspiration, Metaphor, and Intuition

These must remain distinct:

- Evidence: claims supported by credible sources, repeated outcomes, or clear comparative results.
- Inspiration: ideas worth composing from even when they are weakly supported or provisional.
- Metaphor: language that helps orient thought without pretending to literal proof.
- Intuition: artistic judgment that guides selection, emphasis, and expansion before it can be fully justified.

The system should make room for all four while never confusing them.

## Principles for Future Decisions

When making roadmap, product, or editorial decisions, prefer the option that:

1. increases traceability across source -> hypothesis -> recipe -> artifact -> observation
2. makes failures easier to learn from instead of easier to forget
3. shortens the distance between research and real musical practice
4. improves comparability without making the work lifeless
5. protects the distinction between interesting and true
6. rewards ideas that can become compelling music, not only clever experiments
7. strengthens the eventual public narrative by improving internal honesty first
