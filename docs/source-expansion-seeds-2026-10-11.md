## Mathematics follow-up

Direct retrieval verified HTTP 200 and a PDF header. Firecrawl batch parsing had not completed when this note was written, so the content and reuse license still need verification before extraction. Do not count the PDF header as usable research text.

The mathematics shortlist is intentionally narrower than the physics and perception shortlist. A second intake pass should add verified sources on cyclic rhythm, logarithmic pitch/cents, tuning ratios, and combinatorial scale structures rather than compensate with unrelated mathematics papers.

## What the disagreement should fuel

The Milne and McDermott papers measure different outcomes. Milne operationalizes musical stability as finishedness; McDermott asks for pleasantness. Their findings support a useful experiment with separate stability and preference ratings, participant musical experience, controlled timbre, and controlled register. They do not establish that roughness, harmonicity, familiarity, stability, and pleasantness are interchangeable.

Useful first comparisons are a detuning sweep at fixed loudness and timbre, the same tetrads across registers, matched chord progressions with different voice-leading distance, and a harmonic string resonator compared with plate-like inharmonic modes. Each comparison should preserve its source citations and the distinction between a textbook mechanism, a measured result, an opinion, and a project hypothesis.

## Retrieval findings

- Lab Firecrawl REST search and scraping worked. Known URLs proved more reliable than broad searches, several of which returned no results.
- All four attempted PMC HTML pages returned HTTP 203 with only `Cookies must be enabled`. The pages were not usable article captures. A Crawl4AI retry returned HTTP 502. Publisher alternatives returned usable text for PLOS, Springer, and Frontiers.
- Europe PMC's public API verified titles, DOIs, abstracts, and open-access links. Its metadata includes DOI links labeled subscription even alongside open-access mirrors. Confirm the article's actual publisher license rather than reading one metadata availability field as a complete rights determination.
- Several plausible legacy course, textbook, and author URLs returned 404. They were excluded from the verified portfolio. Full-text access, successful extraction, independent corroboration, domain suitability, and reuse rights are separate checks.
- No production database mutations, paid retrieval, or source imports were performed. This note changed only the research shortlist file.
