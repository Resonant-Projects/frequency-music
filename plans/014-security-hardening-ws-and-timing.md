## Why this matters

Two independent, small, high-confidence security hardenings:

1. **`ws` advisory (SEC-04)**: the `ws` WebSocket library is pulled transitively
   at `8.18.0`, inside the vulnerable range `<8.20.1` (GHSA-96hv-2xvq-fx4p, high
   — a WebSocket peer can trigger memory exhaustion / DoS; plus GHSA-58qx-3vcg-4xpx,
   moderate — uninitialized memory disclosure). It reaches runtime through the
   `convex` client (`convex › ws`), not just dev tooling. A patch bump within the
   8.x line closes it with no API change.
2. **Timing-unsafe secret compare (SEC-05)**: `convex/auth.ts` compares the
   dev/CI `AUTH_BYPASS_SECRET` with a plain `===`, even though the same file
   defines and elsewhere uses `constantTimeEqual`. A byte-wise `===` on a shared
   secret is a timing side channel. The exposure is bounded while bypass is
   dev-only, but it couples to the open question of whether bypass is enabled in
   production (tracked separately as SEC-01) — if it ever is, this becomes a
   remotely-reachable timing oracle on the master bypass secret. One-line fix
   using the helper already in the file.

### Part 2 — timing compare

`constantTimeEqual` is defined and correctly used for the agent-tool secret
(`convex/auth.ts:26-46`):

```ts
export function constantTimeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  const encoder = new TextEncoder();
  const bufA = encoder.encode(a);
  const bufB = encoder.encode(b);
  let result = 0;
  for (let i = 0; i < bufA.length; i++) {
    result |= (bufA[i] as number) ^ (bufB[i] as number);
  }
  return result === 0;
}
```

But the bypass-secret compare uses `===` (`convex/auth.ts:76-90`):

```ts
    const providedSecret = options?.devBypassSecret;

    if (
      configuredSecret &&
      providedSecret &&
      providedSecret === configuredSecret        // <-- timing-unsafe
    ) {
      return {
        subject: "system",
        tokenIdentifier: "dev-bypass-token",
        email: "local-dev@resonantrhythm.local",
        name: "Local Dev Bypass",
        isBypass: true,
      };
    }
```
